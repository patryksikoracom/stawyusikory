# PR-6b — minimalny pakiet danych do rozmowy z tatą

Nie trzeba odtwarzać całej historii. Najpierw wybieramy **jeden zamknięty miesiąc**, który da się sprawdzić ręcznie.

## Wiadomość do wysłania

> Tato, chcę sprawdzić wynik jednego miesiąca, nie całą historię. Który ostatni pełny miesiąc najlepiej pamiętasz i masz do niego rozliczenia? Dla tego miesiąca potrzebuję:
>
> 1. listy pobytów z pełnymi cenami;
> 2. kosztu sprzątania każdego domku za pobyt;
> 3. największych kosztów stałych i rachunków: prąd, woda, szambo, serwis, podatki;
> 4. prowizji Booking/Airbnb z panelu albo rozliczenia;
> 5. informacji, czy koszt wspólny dzielimy po równo, czy według przychodu domków.
>
> Przy każdej kwocie wystarczy zdjęcie, plik, nazwa dokumentu albo informacja „mój szacunek z dnia …”.

## Co zapisać przy każdej liczbie

| Pole | Przykład |
|---|---|
| nazwa | energia |
| kwota lub stawka | 850 PLN / miesiąc |
| fakt czy model | faktura / szacunek |
| źródło | FV 12/07/2026 albo panel Booking |
| okres | 01–31.07.2026 |
| zakres | Rybak / wszystkie domki |
| podział kosztu wspólnego | po równo / według przychodu |

## Kolejność

1. Uzupełnić jeden miesiąc.
2. Policzyć ręcznie: `sprzedaż − koszty − prowizje`.
3. Porównać z aplikacją.
4. Wyjaśnić każdą różnicę.
5. Dopiero po zgodności uzupełniać wcześniejsze miesiące.

## Czego teraz nie zbierać

- pełnej historii wszystkich rachunków;
- danych o zwrocie inwestycji i „spłaceniu domku”;
- dokładnych modeli energii, wody i szamba bez potwierdzonego źródła;
- jednej uśrednionej prowizji dla wszystkich platform i lat.

Te dane będą potrzebne później, ale nie blokują sprawdzenia PR-6b na jednej wiarygodnej próbce.
